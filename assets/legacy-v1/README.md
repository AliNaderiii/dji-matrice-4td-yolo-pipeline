# Archived v1 visual material

This folder retains visual files from the repository before the evaluation-safe revision. They are historical qualitative context, not evidence for the current protocol.

- The associated raw PPE data, weights, full Ultralytics run directory, and hardware provenance are not versioned here.
- Any numerical annotations shown in the historical images must not be represented as current v2 results.
- The old material does not validate DJI NPU compatibility, AWS IoT connectivity, edge latency, MQTT throughput, or real-world safety performance.
- New score-bearing visuals may be added only after a recorded v2 experiment supplies its dataset manifest, configuration, checkpoint hash, test metrics, environment, and run history.
